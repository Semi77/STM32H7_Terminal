# CPU统计与HTTP OTA修复说明

OTA部分记录的是旧单分区实现；当前双Bank升级、回滚和首次烧录请以 [A/B OTA说明](ota_ab.md) 为准。下文CPU统计部分仍适用。

## CPU统计

- TIM2独占用于1 MHz、32位自由计数，任务切换时扩展成64位累计时间，不产生统计定时中断。
- FreeRTOS任务运行时间同步使用64位。GUI每秒取总时间和IDLE时间的差值，显示最近一个采样窗口的负载。
- 首次采样、缺失IDLE、空闲时间超过总时间等异常不覆盖上次有效显示。
- 不依赖所有任务运行时间总和，因此自检任务退出不会导致统计失效。
- TIM2相邻采样必须少于约71分钟；当前FreeRTOS任务切换持续采样。今后若增加长时间停止调度或低功耗功能，需要重新评估此约束。

## OTA恢复

下载槽仍为外部Flash的0x00080000，两个参数扇区仍为0x00100000和0x00101000。新增独立恢复保护扇区0x00102000，不得挪作数据存储。

1. 已有DONE记录但内部CRC不符时，重新校验外部镜像并重装。
2. 恢复失败可以重新下载；先将独立保护标记写入并读回，再擦除原参数，保证断电不会启动半写应用。
3. 下载完成不自动安装，包括恢复下载。需要点击“安装固件”；安装意图落盘后，复位才会自动恢复安装。
4. 安装意图、保护标记、内部擦除与编程、内部校验、DONE记录、清除保护标记按顺序执行。任何安装中断都保留恢复信息。
5. App命令仅在应用可启动且无下载或恢复事务时接受。失败会明确回复BOOT_REJECTED，不再用反复复位尝试解除保护。
6. 未完成下载60秒无有效请求时释放会话，保留恢复保护；完整下载不会因等待安装而过期。

USART3改为中断接收和4096字节环形缓冲；协议逐字节非阻塞组帧，250毫秒残帧超时、长度校验、CRC校验及溢出重同步相互独立。Flash和屏幕操作期间仍接收数据。

ESP32对页面命令的确认按类型过滤。App只接受APP_STARTING；周期BOOT_READY不再被当成启动成功。APP_STARTING表示启动请求被接受，不代表应用自检已通过。

## 构建与升级文件

Keil应用工程成功链接后运行`project/shared/package_firmware.py`，需要Python 3，自动生成：

- `project/wangguan/MDK-ARM/wangguan/wangguan.bin`：原始应用，只供调试器烧录。
- `project/wangguan/MDK-ARM/wangguan/wangguan.ota.bin`：HTTP OTA专用文件。

OTA文件在原始BIN之后追加32字节描述：H7FW魔数、格式版本、目标地址、原始长度、原始CRC32、两个保留字段、描述CRC32，均为小端32位整数。上位机先验证构建时生成的描述，再去掉描述发送原始应用。截断、改写、错误目标和无描述原始BIN都拒绝上传。

请先通过调试器更新STM32 Bootloader，并更新ESP32桥接固件和PC上位机，再用新版上位机发送并安装`.ota.bin`。本次ESP32构建产物位于`project/mqtt/build_ota_fix`，原`build`缓存指向移动前的目录，不能直接复用。

曾经OTA后再用调试器替换应用，会导致内部镜像与外部DONE记录不一致；Bootloader会尝试恢复外部记录对应的镜像。建议使用OTA安装新应用以同步镜像和记录。

## 验证范围

- CPU主机测试：计数器回绕、64位时间、窗口负载、已删除任务、非法快照。
- OTA下载测试：分块、重复确认、读回、CRC、最大512 KiB镜像。
- OTA安装测试：安装期间逐步断电、DONE后损坏重装、重新下载时参数擦除断电、恢复保护及显式安装。
- OTA协议测试：分段接收、坏CRC、错误长度、残帧重同步、会话超时、系统毫秒回绕。
- PC测试：本机HTTP上传、丢失确认、取消、安装、文件截断、内容损坏及错误启动回复。

主机测试不能替代开发板测试。实机应验证：CPU空闲与忙碌时数值变化；上传中断60秒后可重试；完整下载等待超过60秒仍可安装；安装中断后重启能恢复；故障镜像不能通过App命令强制启动。

2026-09-18验证结果：STM32应用与Bootloader均为0错误、0警告；ESP32-C3构建和分区容量检查通过；4组C测试通过，其中安装测试覆盖231个首次安装断电点、231个DONE后修复断电点及36个恢复下载准备阶段断电点；14项HTTP/上位机测试通过。最终OTA应用长度399972字节，CRC32为120A5493，解包内容与原始BIN逐字节一致。尚未烧录或进行实机断电测试。
